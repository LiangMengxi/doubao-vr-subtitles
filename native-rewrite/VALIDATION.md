# 本机验证记录

日期：2026-10-19，Asia/Hong_Kong。

## 已通过

- 标准入口 `build.ps1 -Publish`：C++20/MSVC 与 C# WinUI 3，零警告、零错误。
- 构建守卫自测：拒绝手工分配、裸指针声明、业务层借用地址和未封装显存映射。
- 固定依赖：OpenVR 四个 SDK 文件逐一 SHA256 校验；NuGet locked-mode 恢复；本地工具链来自固定下载清单。
- GPU 测试：透明边缘检测、先裁边后裁顶部、最少保留一行、全透明帧、RGBA/BGRA 顺序、预览缩放。
- 显存预算测试：超大输出池拒绝分配、连续尺寸变化达到预算时延后处理、旧纹理退役后恢复。
- 跨语言测试：52 字节选项布局、接口版本 3、拒绝旧版结构尺寸、无效 HWND、NaN、左右倾斜越界、双轴极值、重复停止、SafeBuffer 空预览、销毁后编号失效、编号不复用、读取与销毁并发。
- 双轴数学测试：单轴兼容、俯仰与左右转向独立、16 组组合旋转的正交性及行列式、中心位置保持不变。
- 行为测试：16 种关闭策略组合，开关和双轴角度 JSON 往返、旧配置缺省值；启动自己的受控进程验证路径不匹配不关闭、仅关闭明确选中的已验证进程、重复关闭安全。未为了测试而关闭用户的真实豆包。
- WGC 实测：捕获自己的测试窗口、窗口缩放、静止画面修改顶部裁剪、预览读取、多次启停、切换捕获边框。
- 发布程序启动并自动退出：退出码 0，日志确认原生核心释放。曾发现发布遗漏 App.xbf 和应用 PRI，已修复，并增加缺失资源时终止发布的检查。
- 界面检查：仅保留“豆包VR字幕”名称和功能控件；加号 60%→65%、减号恢复 60%；浅深主题的卡片、文字、按钮完成实际窗口检查。
- 本轮界面检查：移除底部最小化按钮，仅保留系统标题栏最小化；开启自动最小化后，点击叉号由窗口工具确认为 minimized，重新启动可恢复同一窗口；关闭开关后点击叉号正常退出，日志确认先释放核心；上下倾斜 0°→1° 与左右倾斜 0°→−1° 互不覆盖，分别归零并核对保存值；自动最小化开启时底部“退出”仍真正退出。自动启动/退出测试退出码 0，日志确认核心释放完成。
- 原版保护：与首次备份的 SHA256 清单逐一比较，46 个原始文件无内容变化。
- 发布清单：按 `SHA256SUMS.txt` 核对完整程序文件。

## 测试环境限制

初期工作区及其 EXE 报告 Windows Low Mandatory Level，捕获被 Windows 拒绝，因此先使用普通用户应用目录中的完整副本测试。用户调整权限后，最终 `out/app/DoubaoVR.Desktop.exe` 与 `out/core/Release/capture_smoke.exe` 均已确认 Medium Mandatory Level；随后直接从工作区运行 WGC 测试和发布程序启动/退出测试，全部通过，程序退出码为 0。代理未修改工作区权限、系统策略或原版配置。

当前没有运行中的 SteamVR，因此尚未验证真实头显显示、最后一帧延迟、游戏内透明度、SteamVR 退出事件与混合显卡环境。GPU 和桌面捕获测试不能替代这些项目。

旧版托盘及通过关闭图标识别关闭豆包字幕尚未迁移，详见 README。当前产物为重构预览版；真实豆包退出涉及具体安装版本及进程权限，自动测试以受控进程覆盖关闭路径，不替代所有版本的实际兼容验收。

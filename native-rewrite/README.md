# 豆包VR字幕

当前版本：**0.4.2**。旧版发行包保持不变。

## 0.4.0 豆包VR助手

顶栏导航依次为“字幕”“更多调节”“助手”“设置”。新增“助手”页，支持一键唤起并连接豆包对话浮窗、在 SteamVR 中显示浮窗、使用手柄射线点击与滚动、握把抓取移动位置、实时调节浮窗大小（30%–150%，默认 70%），以及短按左手柄摇杆进入／退出空间截图模式、双扳机细淡粉色框选并将截图自动粘贴至豆包浮窗发送框（不自动发送）。默认关闭桌面捕获黄框，可在设置或助手页随时切换。

## 0.3.3 曲面调节

“位置”页更名为“更多调节”，原有控制项不变，新增默认收起的“曲面”分类。0–90°、每次 5°，预设平面 0°／轻微 30°／标准 60°；旧配置和新配置均默认平面。设置持久化并在 VR 开启、调节及重连时应用。

曲面使用 SteamVR 原生水平曲面，只有角度变化时调用曲面接口；不新增纹理或重绘步骤，不改变桌面预览、原有位置／宽度／距离／双轴倾斜、GPU 同步和纹理预算。非零角度失败后尝试恢复平面并报告降级，无法确认平面则停止输出，不假装恢复成功。本机 SteamVR／PICO 已通过独立曲面与佩戴者观察，不代表所有硬件、完整使用场景或长期兼容性均已验收。

- 标题栏随深浅色主题更新。原创实现采用 GPL-3.0-only，详细许可、借鉴声明和对应源码重建方式见仓库根说明及 docs/。

## 0.3.0 新增设置

- 设置按“音频设备”“主题与背景”“字幕捕获”“程序设置”分类，默认收起，点击展开；同一时间仅展开一类。
- 主题色：支持系统色、常用颜色及自定义选择；颜色只应用到本软件，不更改 Windows 主题。
- 背景：选择本机 PNG / JPG / BMP，复制并重新编码到用户配置目录；原图不变，不上传。文件不超过 20 MB、2400 万像素，导入后最长边不超过 1600 像素。不透明度范围 0–100%，与 VR 字幕透明度独立。清理旧背景时只处理本软件生成的文件，保留当前配置与 `.bak` 引用的两份背景。
- 恢复音频：底部增加“恢复音频”，展开音频设置后分别选择播放设备和麦克风、手动刷新。按设备标识保存，不按同名设备猜测；断开时保留选择、提示重新连接，不自动选择替代设备。“不更改”保留该方向的系统默认设备，旧配置不会自动选中麦克风。
- 只在明确点击按钮时设置所选方向的三个默认角色（一般、多媒体、通信），不修改应用单独的路由或 SteamVR 设置。先校验两个目标并读取原默认设备，再执行切换；中途失败会尝试恢复两方向的原默认设备，并核验结果；无法完整恢复时报告失败，不声称成功。
- 播放设备与麦克风枚举使用 Windows MMDevice API；设置默认设备使用参考工具中的 Windows PolicyConfig COM 接口。该设置接口不是微软公开支持的稳定 API，未来 Windows 版本可能需要适配；错误会在界面显示，不调用外部脚本。

当前工程由 C++20 图形核心与 C# WinUI 3 控制界面组成。主分支仅维护这一套实现；旧 Python 工程保留在 v0.2.4 标签与本地备份，不参与当前构建。SteamVR 头显验收和部分旧功能迁移仍需继续验证。

## 使用

普通源码构建后的程序位于 `ui/bin/Release/net8.0-windows10.0.19041.0/win-x64/DoubaoVR.exe`；经过完整本地验收的发布目录为 `out/app/`。完整保留同目录下的 DLL 和资源文件，不能单独复制 EXE。仓库 `scripts/start.cmd` 优先启动最新的源码构建，不会回退到旧 Python 程序。

先在豆包完成登录和实时字幕快捷键设置。点击“开启字幕”，再点击“开启VR”。字幕大小每次加减 5%，距离每次加减 0.1 米；可直接使用大小、距离档位。左右、上下、不透明度提供加减按钮。“上下倾斜”和“左右倾斜”分别控制俯仰和绕竖轴转向，范围均为 ±45°，每次 1°，可分别归零。两种倾斜可同时生效，不改变字幕中心位置。

“设置”提供捕获来源、手动预览连接、裁剪、透明边缘处理、主题和捕获边框，以及两个独立的行为开关：

- “关闭时自动最小化”：开启后，右上角叉号只最小化到任务栏，保留 VR 输出；关闭此开关则正常退出。系统标题栏的最小化按钮照常使用，不再提供底部的重复按钮。
- “退出时同时关闭豆包”：仅点击底部“退出”按钮时生效，先释放 VR 和捕获资源，再关闭已验证路径的豆包进程；不会在点击叉号或最小化时关闭豆包。默认关闭。底部“退出”始终真正退出，不受自动最小化开关影响。

关闭豆包时先请求正常关闭，最多等待 2 秒，再终止仍运行的同路径豆包进程；不会递归终止任意子进程。如果权限不足会提示手动退出。

“开启字幕”在确认字幕窗口存在后变为“关闭字幕”。关闭操作停止捕获和 VR 输出，只识别并点击豆包字幕条的关闭图标，不使用进程退出流程，不修改音频、PICO 或 SteamVR 自启动设置。识别不唯一、目标不是字幕窗口、截图过期或窗口变化时拒绝点击；失败可重试。外部开关字幕时按钮同步，快速重复点击不会重入或立即反向开启。

配置独立保存至 `%LOCALAPPDATA%\DoubaoVR.Native\settings.json`。首次读取旧版 `%LOCALAPPDATA%\DoubaoVR\settings.json` 的显示参数，但不修改旧文件。保存新版配置时保留 `.bak`。日志位于新版目录中的 `logs/native.log`，不记录字幕内容、不保存字幕截图。

## 固定构建方式

需要 Windows x64、PowerShell 7、.NET SDK **8.0.424**。C++ 使用 MSVC、Windows SDK、CMake；可使用已有的 Visual Studio 2022 C++ 工具，或下载本目录内的便携工具链。

```powershell
cd native-rewrite
.\build.ps1 -PrepareToolchain
```

首次准备完成后：

```powershell
.\build.ps1
```

普通源码构建执行源码规范检查、固定版本依赖恢复与 C++/C# 编译，不要求公开仓库包含测试代码。编译警告作为错误处理，普通构建禁止自动更新锁文件。本地有完整验证资料时，完整构建另外执行 GPU、跨语言接口和设置动效逐帧布局检查；任一步失败都会终止。

不使用 vcpkg、Conan、npm、pip 或额外依赖管理器。原生依赖由 PowerShell 直接从固定上游地址下载并验证 SHA256，CMake 只消费本地 SDK。C# 仅使用 .NET 自带 NuGet 恢复 Microsoft 官方组件，使用精确版本和 `packages.lock.json`。开发工具留在 `dependencies/`，不修改系统环境或注册表，不进入发布目录。

`-UiOnly` 可单独构建界面，但不能替代完整验收。维护者使用 `-Publish` 或打包脚本时必须备有完整本地验证资料，缺少资料会终止发布；正式程序不编入动效测试类。从仓库根目录也可使用 `scripts/build.ps1` 和 `scripts/package-release.ps1`，它们调用本目录的同一套流程。本目录的 `scripts/backup-source.ps1` 创建带 SHA256 清单的本地备份，包含当前工程、公共入口、文档以及本机已有的验证资料；这些私有备份不提交到 GitHub。

## 内存和资源约束

- C++ 对象使用智能指针，COM 资源使用 `winrt::com_ptr`，系统事件使用 RAII 句柄；没有手工 `new/delete` 或 `malloc/free`。
- C ABI 使用不复用的整数对象编号，不暴露 C++ 对象地址。登记表持有 `shared_ptr`，并发读取和销毁不会使已获取的对象悬空。
- Windows、D3D11、OpenVR 的 ABI 本身包含指针。业务代码不声明或保存裸指针；不可避免的借用地址、指针数组与映射内存读取集中在 `core/platform.cpp`，不转移所有权、不返回裸地址。
- 显存映射由不可复制的 `ReadMapping` 管理，正常返回与异常退出都会自动 Unmap。捕获会话、帧、COM 线程初始化也有作用域清理。
- C# 使用 `SafeHandle`、`SafeBuffer` 和 `SafeProcessHandle`。禁用 unsafe、裸地址获取和业务层非托管内存分配。
- 字幕 VR 画面留在 GPU 上。透明边界检测仅回读 16 字节，桌面预览最大 640×240、最多约 10 FPS。豆包VR助手的空间截图是明确触发的一次性回读，不套用字幕边界检测的 16 字节限制；助手默认不连接，运行于独立子进程，不共享字幕的 OpenVR 生命周期。
- 在同一快照锁内比较预览序号，未更新时不复制原生／托管像素；后台与已发布图像用两个独立缓冲交换并复用容量，停止释放。不降低预览画质或改变 GPU 同步。当前版本内部 ABI 为 10，新增独立助手及截图接口；v0.3.3 为 ABI 9，v0.3.2 为 ABI 8。核心与界面必须配套构建，不能只替换一个 DLL。
- 绘制视图与输出纹理一起复用、重建和退役，捕获源变化时更新采样视图，避免稳定尺寸下每帧重复创建 SRV／RTV。保留全部 GPU 等待、分辨率与纹理池预算；减少视图创建不等于已证明头显帧率或常驻内存改善。
- 输出纹理池及其延迟释放纹理总预算为 128 MiB。尺寸连续变化导致预算暂满时保留上一帧，等待旧纹理退役后重试。新旧池本身无法共存时，先要求 SteamVR 释放旧纹理，再在原预算内重建完整三纹理池，不降低分辨率；释放失败则停止重建，报告错误并按原有顺序退出清理。重建期间可能有短暂显示空档。本机 SteamVR／PICO 已通过独立 4K 纹理切换专项及佩戴者观察，不代表完整字幕捕获链路、所有设备或长期兼容性验收。该预算不包含 Windows 捕获池、驱动和 SteamVR 自身的分配。
- 捕获源的单张纹理不超过 16,777,216 像素；只保留最新 GPU 快照，不积压字幕帧。

源码检查是构建守卫，不是完整 C++ 静态分析器；它不能证明所有驱动、运行时或第三方实现均无内存问题。验收仍需检查真实设备上的异常退出、重连及长期占用。

## 验证

本地验证资料不提交到主分支。以下是维护者的发布前验收要求，不是公开源码构建的先决条件：GPU 透明裁剪、裁剪顺序、颜色、缩放、双轴旋转矩阵、跨语言布局、参数验证、无效编号、并发销毁、重复停止、关闭策略组合及受控进程退出隔离。自动启动/退出测试不会关闭真实豆包，即使该开关已开启。

本地验证构建通过独立测试窗口检查展开和收起的中间布局帧、下方条目间距、反向中断、快速切换和缩放窗口，不读取或保存用户配置、不切换音频设备。正常桌面且系统启用动画时，必须采集到连续变化的中间高度；系统禁用动画时检查最终布局。该窗口不编入公开源码构建或正式发布程序。

`out/core/Release/capture_smoke.exe` 使用自己的测试窗口验证 WGC、窗口缩放、预览和多次启停，需要正常桌面捕获权限。

仍需 SteamVR 与头显验证实际显示、双轴倾斜观感、延迟、透明度、混合显卡和游戏并行运行。当前未迁移旧版托盘；字幕关闭功能仍需真实豆包版本兼容性实测。受控窗口验证不代表全部旧功能和所有设备组合均已完成兼容验收。

工作区如带 Windows 低完整性标记，生成的 EXE 仍可能无法捕获窗口。测试应使用普通应用目录，保持完整运行文件夹；不要通过修改系统安全策略取得测试结果。

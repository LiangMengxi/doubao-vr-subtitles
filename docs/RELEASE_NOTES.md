# v0.5.2

1. 原生面向 Windows 11（Build 22000+）架构优化，彻底移除旧版兼容模式接口与运行时兼容判断，支持运行中实时开关桌面捕获黄框而无需断开重连。
2. 优化 WGC 窗口捕获管线：新增静态字幕窗口首帧自动唤醒（避免字幕无新文字滚动时长期停留“等待字幕…”），并按 20fps 渲染节奏节流 GPU 纹理拷贝。
3. 加固 SteamVR 待机／摘下头显与线程退出机制：助手交互增加头显待机容错及退出超时保护，隔离超时分离的旧工作线程状态。
4. 修复未配置目标音频设备时点击“恢复音频”跳转页面错误的问题，以及 VRChat OSC 语音同传未优先采用用户所选麦克风的问题。

# v0.5.1

1. 修复 SteamVR 长时间运行或摘下头显进入待机后再操作时“开启 VR”卡住以及关闭时界面卡死的问题，调整 Direct3D 提交刷新顺序并增加工作线程与界面关闭超时保护。

# v0.5.0

1. 新增 VRChat 聊天框同步（OSC 同传）：支持在玩 VRChat 时将自己的麦克风发言实时识别、翻译成外语（支持英语、日语、韩语等），并通过标准 OSC 协议推送到角色头顶聊天框。
2. 接入高精度 SenseVoice 离线语音识别与 Silero VAD 切句引擎：基于纯 CPU 本地推理，不占用显卡显存；首次开启时自动从国内镜像下载量化模型并执行 SHA256 完整性校验，杜绝网络断连或云端 API 依赖。
3. 优化字幕窗口重启无缝定格、截图粘贴视觉校验与 Windows 11 手动兼容模式提示。

# v0.4.2

1. 新增 Windows 10 兼容模式：自动检测系统内部版本（低于 Build 22000 自动启用兼容模式），修复 Windows 10 下因捕获边框属性不支持导致的窗口捕获失败问题，并提供手动兼容模式开关。
2. 新增字幕窗口定时自动重启机制：支持自定义重启间隔（默认 30 分钟），采用“最后一帧画面定格 + 后台无感重启重绑”方案，避免豆包长时间运行历史记录过多导致字幕崩溃，重启期间 VR 与预览画面不黑屏、不闪烁。

# v0.4.1

1. 修复手柄射线指针与真实窗口点击位置偏移问题，确保豆包浮窗 1:1 精准交互。
2. 新增浮窗防飞走与位置重置机制：支持一键将浮窗归位至视野右前方舒适区，并提供“按菜单键自动重置位置”可选开关。

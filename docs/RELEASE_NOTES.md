# v0.3.1

1. 新增 PICO 麦克风延迟改善开关，整合至音频设备设置；思路参考 [PicoStreamingMicrophoneKeeper](https://github.com/Kill11/PicoStreamingMicrophoneKeeper)，独立实现并附借鉴声明。
2. 新增随 SteamVR 启动的注册设置，可一键开启或取消。
3. 优化深浅色标题栏，精简音频设置界面。
4. 增加 GPL-3.0 开源许可证及对应源码包。

PICO 延迟改善效果及 SteamVR 自启动兼容性仍需实际头显环境验证。

# v0.3.0

1. 新增一键恢复音频功能，可从 VR 头显快速切回预设的电脑播放设备和麦克风。
2. 新增主题个性化设置，支持自定义主题色、背景图片及背景透明度。

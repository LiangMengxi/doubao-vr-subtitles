# v0.4.2

1. 新增 Windows 10 兼容模式：自动检测系统内部版本（低于 Build 22000 自动启用兼容模式），修复 Windows 10 下因捕获边框属性不支持导致的窗口捕获失败问题，并提供手动兼容模式开关。
2. 新增字幕窗口定时自动重启机制：支持自定义重启间隔（默认 30 分钟），采用“最后一帧画面定格 + 后台无感重启重绑”方案，避免豆包长时间运行历史记录过多导致字幕崩溃，重启期间 VR 与预览画面不黑屏、不闪烁。

# v0.4.1

1. 修复手柄射线指针与真实窗口点击位置偏移问题，确保豆包浮窗 1:1 精准交互。
2. 新增浮窗防飞走与位置重置机制：支持一键将浮窗归位至视野右前方舒适区，并提供“按菜单键自动重置位置”可选开关。

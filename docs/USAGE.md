# 豆包VR字幕使用说明

## v0.3.3 曲面调节

“位置”页更名为“更多调节”，原有位置、不透明度和双轴倾斜仍保留。点击默认收起的“曲面”分类，可使用滑块、加减按钮或“平面／轻微／标准”档位调节。

曲面范围为 0–90°，每次加减 5°；平面为 0°、轻微为 30°、标准为 60°。它只改变 SteamVR 悬浮层的水平弯曲，不扭曲字幕纹理，也不改变桌面预览、字幕宽度参数、距离或独立倾斜。旧配置默认平面，调节自动保存；VR 开启时实时应用，重连后重新应用。

运行时拒绝曲面设置时，程序尝试恢复平面并在原状态区域提示；无法确认恢复平面时会停止字幕输出并报告错误。选择“平面”后再选择曲面，或重连 VR，可重试。实际效果与兼容性取决于头显及运行环境，不能保证所有设备组合一致。v0.3.2 不包含此功能，旧版仍使用“位置”页。

## v0.3.2 字幕开关与设置

“开启字幕”在确认豆包字幕已打开后变为“关闭字幕”。再次点击会先停止捕获和 VR 输出，再识别并操作字幕条的关闭图标；不会退出豆包主程序，也不受“退出时同时关闭豆包”设置影响。外部开关字幕后，按钮自动同步。识别失败不会假装关闭成功，可展开字幕条重试或点击豆包自身的关闭按钮。

此功能自 v0.3.2 提供；实际豆包版本与头显兼容性待实测。

“设置 → 关于”显示当前构建版本、可点击的 GitHub 项目地址和 QQ：1585759606。分类默认收起，点击后展开。

持续拖动滑块或长按加减时，运行参数按节流持续应用；停止操作后异步保存设置。切页和最小化只影响预览，不写设置。背景导入、引用保存及旧图清理统一串行，保留当前与备份引用的图片，不修改所选原图。

## v0.3.1 新增设置

- “设置 → 音频设备 → 改善PICO麦克风延迟”：默认关闭。开启后自动等待名称匹配的 PICO 串流麦克风，以共享模式持续消费音频包并丢弃；不保存、不上传，不更改电脑默认音频设备。设备断开会重试，关闭开关或退出程序后释放。Windows 的麦克风使用提示属于正常现象，改善效果取决于实际头显、驱动和串流环境。
- “设置 → 程序设置 → 随SteamVR启动”：开启时注册本程序并设置 SteamVR 自动启动，关闭时取消注册。不写 Windows 开机启动项。注册需要已安装 SteamVR；失败会显示原因，不把失败操作标为已注册。移动免安装目录或改用其他安装目录后，请在新位置重新注册。
- v0.3.2 在修改启动项前读取 SteamVR 实际状态；失败时尝试恢复原清单、注册与自动启动状态。若超时后无法核实或发现外部修改，会保留 `%LOCALAPPDATA%\DoubaoVR.Native\steamvr\transaction-*.json` 恢复记录并暂停进一步修改；先核对 SteamVR 启动项和记录，不要直接删除记录后反复切换。v0.3.1 不包含此事务改进。
- 标题栏及未激活时的按钮颜色随浅色、深色和跟随系统模式更新；高对比度模式使用系统颜色。主界面不增加这两项功能的额外按钮。
- 本项目原创源码采用 GPL-3.0-only，借鉴来源与边界见 [借鉴说明](REFERENCES.md)，源码重建见 [构建说明](SOURCE_BUILD.md)。

## v0.3.0 新增功能

- “设置”分为“音频设备”“主题与背景”“字幕捕获”“程序设置”，默认收起，点击分类展开；展开另一类时自动收起上一类。
- 展开“主题与背景”，可选择系统、蓝、紫、绿主题色，或使用“自定义”选择颜色。
- “选择背景图片”支持本机 PNG、JPG、BMP；图片复制到用户配置目录，不上传、不修改原图。可调节“背景不透明度”，0% 隐藏、100% 完全显示，也可移除图片。只作用于桌面界面，不影响 VR 字幕透明度。
- 展开“音频设备”，分别选择平时使用的“播放设备”和“麦克风”，再点击底部“恢复音频”，将已选择方向的一般、多媒体、通信默认设备恢复到对应目标。“不更改”表示不切换该方向；两项均未选择时，按钮会打开音频设置，不切换设备。原有播放设备选择会保留，不自动选择麦克风。
- 切换前核验两个目标；其中一项无效时不执行切换。切换中途失败会尝试恢复两方向的原默认设备，并报告不能完整回退的情况。
- 不会在启动、退出或插拔 VR 时自动切换。目标设备失联时保留原选择，不自动改用其他设备；连接后可点击“刷新设备”。部分自行指定音频设备的程序可能需要在其自身设置中调整。

## 第一次使用

1. 从 Releases 下载 `DoubaoVR-v0.3.3-Setup-x64.exe` 并安装；升级时安装器默认沿用原路径，也可以重新选择。
2. 或下载 ZIP，完整解压到普通应用目录，运行 `DoubaoVR.exe`。无需安装 Python 或 .NET。
3. 在豆包桌面版登录，设置实时字幕快捷键，手动确认字幕功能可用。
4. 启动 SteamVR 并连接头显。
5. 打开“豆包VR字幕”，点击“开启字幕”，等待预览出现后点击“开启VR”。

字幕桥读取豆包现有快捷键，不要求固定为 Alt+Z，也不修改豆包配置。首次登录、授权及更新提示需要在豆包中自行处理。

## 调整显示

“字幕”页提供大小与距离滑块、加减按钮和常用档位。大小每次加减 5%，距离每次加减 0.1 米。大小 100% 对应宽度 1 米。

“更多调节”页提供左右、上下、不透明度，以及独立的“上下倾斜”和“左右倾斜”。上下倾斜控制俯仰，左右倾斜控制绕竖轴转向；范围均为 ±45°，每次 1°，可分别归零。两个方向可同时调整，不改变字幕中心；展开“曲面”可调节水平弯曲。

“设置”页可选择捕获窗口、刷新、连接或停止预览，调整顶部裁剪、透明裁边、主题及捕获黄框。顶部裁剪默认 0；隐藏工具栏档位为 44 像素，需根据豆包版本自行调整。

滑块两侧加减按钮支持按住连续调节。设置自动保存。

## 最小化与退出

- 标题栏最小化按钮按普通软件方式最小化到任务栏，不关闭 VR。
- 开启“关闭时自动最小化”后，右上角叉号也只最小化；关闭该设置则正常退出。
- 底部“退出”始终退出，不受自动最小化设置影响，退出前释放 VR 和捕获资源。
- “退出时同时关闭豆包”默认关闭，开启后仅在点击底部“退出”时关闭豆包；叉号或最小化不会关闭豆包。
- 再次运行程序或使用任务栏可以恢复窗口。

此版本不提供系统托盘。可通过同一字幕按钮单独关闭豆包字幕；识别失败时使用豆包自身按钮。

## 配置与升级

新配置：`%LOCALAPPDATA%\DoubaoVR.Native\settings.json`，保存时保留 `.bak`。日志：同目录下 `logs\native.log`，不保存字幕内容或截图。

首次运行读取旧版 `%LOCALAPPDATA%\DoubaoVR\settings.json` 的兼容字段，不覆盖旧配置。已有新版配置优先。安装、升级、卸载不清空上述用户目录。

## 排错

- 找不到字幕：确认豆包已登录、快捷键有效、字幕窗口已展开；到“设置”刷新并确认捕获来源。
- 字幕不更新：先确认豆包自身字幕在更新；静止画面没有新帧属于正常行为。不要最小化、关闭或收起豆包字幕窗口。
- 预览为空或捕获失败：确认来源正确、豆包与字幕桥权限一致，并使用普通应用目录。不要通过降低 Windows 安全策略解决捕获问题。
- VR 无法开启：确认 SteamVR 与头显就绪。仅支持 SteamVR，不支持原生 OpenXR 会话。
- 看不到 VR 字幕：检查大小、距离、位置和透明度；桌面预览成功不等于头显显示已经验证。
- 豆包未完全关闭：可能存在权限限制，从豆包托盘手动退出即可。
- 下载后无法启动：确保 EXE、DLL 和资源完整保留，核对 SHA256；不要用安装 EXE 代替主程序。

当前版本的实际头显、混合显卡和不同豆包版本兼容性仍需实机确认。
